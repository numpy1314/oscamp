## 简介

oscamp 是基于 ArceOS 操作系统的实验性操作系统课程项目。ArceOS 是一个用 Rust 编写的实验性模块化操作系统（或单内核），受到 Unikraft 的启发。本指南将帮助您从零开始配置开发环境并运行第一个示例程序。

### 核心特性
- 支持多种架构：x86_64、riscv64、aarch64
- 多平台支持：QEMU pc-q35（x86_64）、virt（riscv64/aarch64）
- 多线程支持
- 虚拟化网络和块设备驱动
- TCP/UDP 网络栈
- 文件系统支持

## 系统要求

### 支持的操作系统
- **Linux**：推荐 Ubuntu 20.04+ 或 Debian 11+
- **macOS**：需要 Homebrew 包管理器
- **Windows**：建议使用 WSL2（Windows Subsystem for Linux）

### 硬件要求
- CPU：支持虚拟化的处理器
- 内存：至少 4GB RAM
- 存储：至少 20GB 可用空间

## 构建依赖安装

### 1. 安装 Rust 工具链

首先需要安装 Rust 工具链，oscamp 使用特定版本的 Rust：

```bash
# 安装 rustup（如果尚未安装）
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# 加载环境变量
source ~/.cargo/env

# 安装指定版本的 Rust 工具链
rustup install nightly-2024-09-04
rustup default nightly-2024-09-04
```

### 2. 安装 cargo-binutils

cargo-binutils 提供了 `rust-objcopy` 和 `rust-objdump` 工具：

```bash
cargo install cargo-binutils
```

### 3. 安装 musl 工具链

根据目标架构下载并安装 musl 工具链：

```bash
# 下载工具链（以 riscv64 为例）
wget https://musl.cc/riscv64-linux-musl-cross.tgz
tar zxf riscv64-linux-musl-cross.tgz

# 添加到 PATH（临时）
export PATH=`pwd`/riscv64-linux-musl-cross/bin:$PATH

# 或永久添加到 ~/.bashrc
echo 'export PATH=`pwd`/riscv64-linux-musl-cross/bin:$PATH' >> ~/.bashrc
source ~/.bashrc
```

对于多架构支持，可以同时安装：
```bash
# 下载所有架构的工具链
wget https://musl.cc/aarch64-linux-musl-cross.tgz
wget https://musl.cc/riscv64-linux-musl-cross.tgz
wget https://musl.cc/x86_64-linux-musl-cross.tgz

# 解压并添加到 PATH
tar zxf aarch64-linux-musl-cross.tgz
tar zxf riscv64-linux-musl-cross.tgz
tar zxf x86_64-linux-musl-cross.tgz

export PATH=`pwd`/x86_64-linux-musl-cross/bin:`pwd`/aarch64-linux-musl-cross/bin:`pwd`/riscv64-linux-musl-cross/bin:$PATH
```

### 4. 安装 libclang-dev

这是编译 C 应用程序所需的依赖：

```bash
# 对于 Debian/Ubuntu 系统
sudo apt install libclang-dev

# 对于 macOS 系统
brew install llvm
```

### 5. 安装 QEMU

QEMU 是用于模拟目标硬件的虚拟机：

```bash
# 对于 Debian/Ubuntu 系统
sudo apt-get install qemu-system

# 对于 macOS 系统
brew install qemu

# 其他系统请参考官方下载页面
# https://www.qemu.org/download/#linux
```

### 6. 安装额外工具

```bash
# 安装 dosfstools（用于创建磁盘镜像）
sudo apt install dosfstools

# 安装 wget（用于下载工具链）
sudo apt install wget
```

## Makefile 参数详解

oscamp 使用 Makefile 进行构建和运行控制，理解其参数对成功运行示例至关重要。

### 通用参数

| 参数 | 描述 | 默认值 | 示例 |
|------|------|--------|------|
| `ARCH` | 目标架构 | `riscv64` | `ARCH=x86_64` |
| `PLATFORM` | 目标平台 | 自动检测 | `PLATFORM=aarch64-qemu-virt` |
| `SMP` | CPU 核心数 | `1` | `SMP=4` |
| `MODE` | 构建模式 | `release` | `MODE=debug` |
| `LOG` | 日志级别 | `warn` | `LOG=info` |
| `V` | 详细程度 | 空 | `V=1` |

### 应用参数

| 参数 | 描述 | 默认值 | 示例 |
|------|------|--------|------|
| `A` 或 `APP` | 应用程序路径 | `tour/u_1_0` | `A=examples/helloworld` |
| `FEATURES` | 启用的功能模块 | 空 | `FEATURES=net,fs` |
| `APP_FEATURES` | 应用程序功能 | 空 | `APP_FEATURES=alloc` |

### QEMU 参数

| 参数 | 描述 | 默认值 | 示例 |
|------|------|--------|------|
| `BLK` | 启用存储设备 | `n` | `BLK=y` |
| `NET` | 启用网络设备 | `n` | `NET=y` |
| `GRAPHIC` | 启用图形输出 | `n` | `GRAPHIC=y` |
| `BUS` | 设备总线类型 | `pci` | `BUS=mmio` |
| `ACCEL` | 启用硬件加速 | 自动检测 | `ACCEL=y` |

### 网络参数

| 参数 | 描述 | 默认值 | 示例 |
|------|------|--------|------|
| `IP` | ArceOS IPv4 地址 | `10.0.2.15` | `IP=192.168.1.100` |
| `GW` | 网关地址 | `10.0.2.2` | `GW=192.168.1.1` |
| `NET_DEV` | 网络后端类型 | `user` | `NET_DEV=tap` |

### 基本命令格式

```bash
# 构建应用程序
make A=path/to/app ARCH=<arch> LOG=<log>

# 构建并运行应用程序
make run A=path/to/app ARCH=<arch> LOG=<log>

# 清理构建文件
make clean
```

### 示例 5：自定义应用程序

创建一个新的 Rust 应用程序：

```bash
# 1. 创建新项目目录
mkdir my_app
cd my_app

# 2. 创建 Cargo.toml
cat > Cargo.toml << EOF
[package]
name = "my_app"
version = "0.1.0"
edition = "2021"

[dependencies]
axstd = { path = "/path/to/arceos/ulib/axstd" }
EOF

# 3. 创建 main.rs
cat > src/main.rs << EOF
#![no_std]
#![no_main]

use axstd::println;

#[no_mangle]
fn main() {
    println!("My first ArceOS app!");
}
EOF

# 4. 返回 arceos 目录并运行
cd ../arceos
make run A=../my_app ARCH=riscv64
```

## 常见问题与解决方案

### 1. 路径错误

**问题：** `Application path "path/to/app" is not valid`

**解决方案：**
```bash
# 确保使用相对路径
make run A=./examples/helloworld ARCH=riscv64

# 或者在应用程序目录下运行
cd examples/helloworld
make -C ../../arceos run ARCH=riscv64
```

### 2. 依赖缺失

**问题：** `command not found: qemu-system-riscv64`

**解决方案：**
```bash
# 安装 QEMU
sudo apt install qemu-system-misc  # Ubuntu/Debian
brew install qemu                  # macOS
```

### 3. 工具链问题

**问题：** `error: toolchain 'nightly-2024-09-04-x86_64-unknown-linux-gnu' is not installed`

**解决方案：**
```bash
# 安装正确的 Rust 工具链
rustup install nightly-2024-09-04
rustup default nightly-2024-09-04
```

### 4. 权限问题

**问题：** `Permission denied` 或 `Operation not permitted`

**解决方案：**
```bash
# 给脚本执行权限
chmod +x update_disk.sh

# 或使用 sudo（谨慎使用）
sudo ./update_disk.sh payload/origin/origin
```

### 5. 磁盘镜像问题

**问题：** `disk.img doesn't exist! Please 'make disk_img'`

**解决方案：**
```bash
# 删除旧的镜像并重新创建
rm disk.img
make disk_img
```

### 6. 内存不足

**问题：** `Cannot allocate memory`

**解决方案：**
```bash
# 关闭不必要的应用程序释放内存
free -h

# 或增加交换空间
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
```

### 7. 网络连接问题

**问题：** 无法访问网络服务

**解决方案：**
```bash
# 检查网络配置
make run A=examples/httpserver NET=y LOG=debug

# 或尝试不同的网络后端
make run A=examples/httpserver NET=y NET_DEV=tap
```

### 8. 调试技巧

```bash
# 启用详细输出
make run A=tour/u_1_0 V=1

# 启用调试日志
make run A=tour/u_1_0 LOG=debug

# 使用调试模式
make debug A=tour/u_1_0
```

## 进阶使用

### 1. 自定义平台配置

创建自定义平台配置：

```bash
# 创建平台配置文件
cat > my-platform.toml << EOF
arch = "riscv64"
platform = "my-custom-platform"
family = "custom"

phys-memory-base = "0x8000_0000"
phys-memory-size = "0x800_0000"
kernel-base-paddr = "0x8020_0000"
kernel-base-vaddr = "0xffff_ffc0_8020_0000"
phys-virt-offset = "0xffff_ffc0_0000_0000"
EOF

# 使用自定义平台
make run A=tour/u_1_0 PLATFORM=my-platform.toml
```

### 2. 功能模块选择

```bash
# 启用特定功能
make run A=examples/httpserver ARCH=riscv64 FEATURES=net,fs

# 启用更多功能
make run A=examples/shell ARCH=riscv64 FEATURES=net,fs,alloc
```

### 3. 性能调优

```bash
# 多核运行
make run A=tour/u_1_0 SMP=4

# 发布模式构建（更快）
make run A=tour/u_1_0 MODE=release

# 禁用日志（最快）
make run A=tour/u_1_0 LOG=off
```

### 4. 网络配置

```bash
# 配置静态 IP
make run A=examples/httpserver NET=y IP=192.168.1.100 GW=192.168.1.1

# 使用桥接网络
make run A=examples/httpserver NET=y NET_DEV=bridge
```

### 5. 存储配置

```bash
# 启用块设备
make run A=tour/u_7_0 BLK=y

# 使用自定义磁盘镜像
make DISK_IMG=my-disk.img run A=tour/u_7_0 BLK=y
```
